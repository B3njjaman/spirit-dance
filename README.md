# Spirit Dance Academy

Sitio de la academia de danza infantil de Paulina Quezada, en La Florida.

- `npm run dev`: servidor local en http://localhost:3100
- Cada push a `main` construye el sitio estático y lo publica en GitHub Pages (`.github/workflows/pages.yml`).

Stack: Next.js 15 (export estático), Three.js con react-three-fiber para el logo 3D, GSAP ScrollTrigger y Lenis para el scroll, framer-motion para las historias.
